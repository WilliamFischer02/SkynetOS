Re-read docs/06-ROADMAP.md. For milestone M$ARGUMENTS:

1. State its exit criterion verbatim.
2. List the vertical slices it decomposes into, smallest first.
3. Confirm the previous milestone's exit criterion is actually met — with evidence, not assertion. If it isn't, stop and say so.
4. Build slice by slice. After each: run `npm run verify`, report pass/fail.
5. When the exit criterion is met, demonstrate it concretely and update handoff.md.

Do not claim the milestone complete without demonstrating the exit criterion.
